# Release Notes - v1.0.3 (Code: 4)

## What's New in v1.0.3
- **Italian Language Support**: Added full Italian (it) localization, expanding multi-language support to 14 languages.
- **Folder Image to PDF Conversion**: Enhanced capability to open image folders, sort images by name/creation/modification, and convert them seamlessly into high-quality PDFs.
- **Margin Cropping**: Added precise margin cropping options for scanned documents.
- **Diagnostics & Audit Logs**: Improved local 24-hour rolling audit logs and diagnostic tests for smooth troubleshooting.
- **ChromeOS & Tablet Optimization**: Refined desktop keyboard shortcuts, mouse context menus, and multi-pane layouts.
