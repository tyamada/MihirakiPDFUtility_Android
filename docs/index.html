About the App

Mihiraki PDF Utility is a feature-rich tool designed for readers and creators. Whether you're organizing scanned books (Jisui), merging documents, or reordering pages, our intuitive interface makes it effortless.

Key Features

Spread (Mihiraki) View

View two pages side-by-side. Supports both LTR and RTL reading directions for manga and books.

Smart Splitting

Split double-page spreads into individual pages. Supports vertical and horizontal splitting.

Drag & Drop Reordering

Organize your PDF by simply dragging thumbnails. Move single or multiple pages at once.

Merge & Append

Combine multiple PDF files into a single document easily.

Diagnostics & Benchmarks

Run in-app comprehensive diagnostics and benchmark tests (functional tests, editing feature tests, 1000-page load tests, search performance tests) using dynamic in-app generated test PDFs, and review privacy-protected local audit logs (24-hour retention, offline processing with no external transmission).

Adaptive Menu & Customization

Adaptive layout: horizontal menu bar at widths of 840 dp or more, and a categorized, scrollable bottom sheet menu on smaller screens, plus customizable toolbar buttons via Options.

Interactive Tutorial

Guided step-by-step tutorial screen for first-time users with a "Don't show again" option, instant sample PDF trial, and re-triggerable help.

Cross-Device Usage

The app is designed to provide a seamless experience across various Android form factors, including phones, tablets, and desktop environments like ChromeOS.
