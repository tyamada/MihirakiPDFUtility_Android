Sử dụng trang GitHub Issues để báo cáo lỗi hoặc yêu cầu tính năng.

Các GitHub Issue là công khai. Chỉ gửi thông tin cần thiết để giải thích sự cố. Hãy xóa tên, mã nhận dạng tài khoản, nội dung PDF và ảnh chụp màn hình hoặc chi tiết nhật ký không cần thiết. Việc mở trang issue hoặc sao chép dữ liệu chẩn đoán không đồng nghĩa với việc gửi báo cáo.
