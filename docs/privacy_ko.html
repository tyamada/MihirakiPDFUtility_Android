개인정보처리방침

1. 기기 내 처리 및 사용자가 전송을 선택한 정보

미히라키 PDF 유틸리티은(는) 기기 내에서 PDF를 처리합니다. 앱은 PDF 내용, 진단 정보 또는 로그를 개발자에게 자동으로 업로드하지 않습니다. 원본 PDF, 작업 복사본, 설정 및 로그는 사용자가 이용하는 기능을 위해 로컬에 저장될 수 있습니다.

진단 정보를 복사하거나, 다른 앱과 로그를 공유하거나, 지원 요청을 제출하도록 선택할 수 있습니다. 사용자가 전송한 정보는 선택한 대상이 수신할 수 있으며, 본 프로젝트로 접수된 보고의 경우 개발자가 수신할 수 있습니다. 전송하기 전에 내용과 수신자를 확인하세요.

2. 인앱 결제에 관하여

본 앱에는 개발을 지원하기 위한 선택적 인앱 결제(팁)가 포함되어 있습니다. 이러한 거래는 Google Play 결제 시스템을 통해 안전하게 처리됩니다.

3. 권한에 관하여

앱은 사용자가 선택한 파일을 사용하여 PDF를 열고, 편집하고, 저장하고, 내보냅니다. 재시작 후 다시 열 수 있도록 마지막으로 성공적으로 열었던 원본 PDF의 로컬 복사본을 유지할 수 있습니다. 저장되지 않은 편집 내용 및 Undo 기록은 자동으로 저장되지 않습니다. 샘플 다운로드는 GitHub에 연결되며, GitHub은 자체 정책에 따라 연결 데이터를 처리합니다.

4. 정책 변경

본 개인정보처리방침은 수시로 업데이트될 수 있습니다.

5. 로컬 로그 및 지원 복사본

로컬 로그에는 24시간 정리 기준이 적용됩니다. 정리는 항목 타임스탬프 또는 파일 수정 시간을 사용하여 관련 로깅 기능이 실행될 때 동작합니다. 특히 앱이 실행 중이지 않을 때 생성 후 정확히 24시간 뒤에 모든 항목이 삭제된다는 것을 보장하지는 않습니다.

로컬 정리는 이미 제출된 보고, 내보낸 복사본, 또는 다른 앱, 서비스 제공업체나 백업에 보관된 복사본을 삭제하지 않습니다. 이러한 항목들의 보관 및 삭제는 별도로 관리됩니다.

개발자가 관리하는 지원 복사본의 경우, 삭제 목표는 문의 건이 종결된 후 90일입니다. 불필요한 복사본은 더 일찍 삭제됩니다. 종결되지 않은 건과 제한적인 예외 사항은 매주 검토됩니다. 이 목표치가 공개된 GitHub Issues나 모든 외부 복사본 및 백업을 자동으로 삭제하는 것은 아닙니다.

6. 지원 요청 보고 및 공개 게시물

문제를 설명하는 데 필요한 내용만 전송하세요. 개발자가 수신한 지원 정보는 요청에 답변하고 문제를 조사하는 데 사용됩니다. 이름, 계정 핸들, 메시지 본문 및 첨부 파일은 통상적으로 별도의 추적 시트에 복사되지 않습니다. 추적이 필요한 경우 문의 ID, 이슈 링크, 날짜, 상태 및 삭제 기록만 유지합니다.

GitHub Issues는 공개되어 있습니다. 프로필 정보, 게시물 및 첨부 파일은 GitHub 정책에 따라 처리됩니다. 본인의 댓글을 편집하거나 삭제하는 것은 전체 이슈를 삭제하는 것과 다르며, 전체 이슈 삭제는 저장소 소유자 또는 권한이 있는 관리자여야 가능합니다.

본 프로젝트에 제출한 보고서 내 정보의 삭제를 요청하려면 원래의 지원 창구를 통해 개발자에게 문의하세요. 공개 요청에 민감한 정보를 다시 게시하지 마세요. 공개 게시물, 서비스 기록, 캐시 및 백업에는 별도의 제어 방식이 적용되므로, 앱이 모든 복사본의 삭제를 보장할 수는 없습니다.
