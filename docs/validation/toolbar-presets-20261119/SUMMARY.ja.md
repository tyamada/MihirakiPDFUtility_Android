# ツールバー自動設定・縦横別表示設定（2026-11-19）

BetaLobbyの「初回に使い方が分からない」「ホーム画面の機能が密集している」という2件の提案を踏まえた変更。既存の開始画面（PDFを開く＋説明、文書未読込時は編集ボタン非表示）は保持した。

## 仕様

- オプション先頭に標準（Standard）、シンプル（Simple）、コンパクト（Compact）、すべて表示、すべて非表示を追加。
- 新規設定の初期値は標準：アイコン＋テキスト、2行以内。シンプルは同形式で1行、コンパクトはアイコンのみで2行以内。
- 自動設定は縦横両方へ適用し、表示幅・文字サイズ・表示言語に応じて実際のツールバーの幅で再計算。既存の表示順の先頭から選ぶ。デスクトップの設定や更新通知ボタンがある場合はその幅も確保。
- 手動のチェック変更は選択した向きだけを個別設定へ変更。表示形式は縦横共通。「適用」で保存し「キャンセル」で破棄。画面回転時の編集途中の値はrememberSaveableで保持する設計。
- 旧設定は保存済みの形式・表示対象を保持して縦横へ引き継ぐ。明示的な空集合も保持。
- 反対向きのオプション一覧は画面寸法からのプレビュー。実際に表示するツールバーはその時点の測定幅を使う。
