# LOCAL版 文書・ボタン設定保持の修正とPixel 8a再検証

2026-11-16（日本時間）。前回2026-11-15のアプリ停止・再起動後の不保持を修正し、Pixel 8a／Android 17で再確認した。

## 修正

- ボタン表示形式と表示対象セットをSharedPreferencesへ保存し、ViewModel生成時に復元。空セットと未設定を区別し、未知の値は安全に処理する。
- 最後に正常読込したPDFの復元用コピーと名前・サンプル区分をアプリ専用noBackupFilesDirへ保存。GetContentの一時URI権限やキャッシュの寿命に依存せず、起動時に開き直す。明示的な外部ファイル指定がある場合はそちらを優先する。
- コピー作成・読込・描画確認後にAtomicFileで記録を確定。失敗時は前の正常な記録を保持し、不要な候補コピーを除去。入替時の削除はこのストアが所有するコピーに限定。元PDFは変更しない。
- パスワードは保存しない。暗号化PDFの復元は再入力経路を使う設計。ただし今回は暗号化PDFの一連の実機操作は未検証。

今回の「再起動」はアプリの強制停止後の再起動。端末OS全体の再起動は未実施。復元するのは最後に開いた元PDFであり、未保存の回転・削除・結合などの編集やUndo履歴、読書位置の自動保存ではない。

## 検証・成果物

- assembleDebug成功。既存単体試験23件、失敗0。Lintエラー0、警告7。
- 新規端末回帰試験5件をPixel 8aで実行し全件成功。元ファイル削除後のコピー保持、失敗時の前文書維持、コピー入替・原本保全、全3表示形式と空のボタン選択、未知の設定値を検証。
- 既存BillingManagerTestの旧課金API不整合があるため、端末テストAPKのビルド時だけ当該ファイルを一時退避し、必ずバイト一致で復元。全端末テストが通ったという扱いにはしない。実行対象は今回の5件に限定。
- 修正したファイルは5件のみ。初回の修正・実機検証は新SSD作業コピーで実施。2026-11-16に、この保持修正5ファイルだけを元リポジトリにも反映し、検証記録とともにコミット対象とした。ホーム改善v2やLOCAL識別用ビルド設定などの別変更は含めない。Play Console操作はなし。

実機検証したソースは、既存のホーム改善v2を含むLOCAL作業コピー。リポジトリへは保持修正の差分だけを反映した。

実機検証APKは別ID `com.takumayamada22.pdfutility.homepreview`、1.2.10-home-v2-local（26）、既存LOCALと同じデバッグ署名（SHA-256: 824e1cdeb518969fc10634b44a957883c49dfafec6d75cd14c98fcbae1245098）。公開・提出用ではない。APK SHA-256: 25e42ef730035608f42daf11d7099fd1a31ab58869ff44e875f0f82e0edbede4。端末導入後のAPKとも一致。リポジトリのビルド番号・applicationId・署名設定は今回変更しない。

[機械可読検証結果](VERIFICATION.json)、[端末回帰試験ログ](instrumentation-result.txt)。日本語前後・英語後の画面XMLとPNGはローカル検証成果物に保持し、リポジトリへAPK・端末識別情報・生の設定画面は追加しない。

## リポジトリ反映時の検証

最新origin/mainを基点とする独立作業ツリーに保持修正だけを適用して検証する。元作業ツリーの既存差分は保持する。独立ツリーでのビルド・単体試験・Lintの結果はVERIFICATION.jsonのrepository_validationに記録する。ここで生成した通常debug APKは端末へ導入しない。

リポジトリ反映時の独立検証も成功: assembleDebug、単体試験19件（失敗・エラー0）、Lintエラー0・警告7。LOCAL作業コピーの23件とは対象基点が異なるため件数を区別する。今回の修正5ファイルは実機検証したソースとすべてバイト一致。
