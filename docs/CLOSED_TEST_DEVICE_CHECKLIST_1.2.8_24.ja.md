# ユーティリティ1.2.8（24）：実機再確認

1.2.7（23）の結果は履歴として保持し、修正版の結果は別に記録する。旧版で不合格だった1・3・5・8・9を重点確認し、全9項目を再確認する。配信・端末への反映には時間がかかる場合がある。

1. **Playから上書き更新**：既存テスターのGoogleアカウントで[参加ページ](https://play.google.com/apps/testing/com.takumayamada22.pdfutility)を開き、Playから更新。アンインストールしない。アプリのバージョン画面で1.2.8（24）を確認し、更新前の設定・購入済み表示・保存済みサンプルが保持されていることを確認。
2. **サンプルPDF**：Releasesの新URLから取得する更新版で、日本語と英語などで未保存サンプルをダウンロードして開く。保存済みサンプルも開けることを確認。試験で新規保存したサンプルだけ削除・再取得できることを確認。
3. **言語フィルターとソート**：言語名が原語＋英語名、英語名順であること、日本語等の各言語3件、「すべて」で42件を確認。第1話順／最新話順を切り替える。言語絞り込みと「すべて」で順序を確認。アプリ終了・再起動後も並び順が維持されることを確認。
4. **編集と別名保存**：試験用PDFのコピーで、選択・回転・移動・分割・削除・白紙追加を操作。元を上書きせず別名保存し、保存したPDFを開き直してページ数・順序・向き・内容を確認。可能ならビューアなど別アプリでも確認。
5. **パスワードと文書情報**：試験用PDFに一時的なパスワードとタイトルを設定して別名保存。正しいパスワードで開け、誤ったパスワードでは開けないこと、文書情報が保持されることを確認。実際の機密PDFや普段使うパスワードは使わない。
6. **画像フォルダから生成**：試験画像を選び、並び順を変えてPDFを生成。開き直して画像の順序・ページ数を確認。キャンセル時に元画像を変更しないことを確認。
7. **大きい文字と応援画面**：Pixel 8a／Android17などで、文字サイズ「最大から1段階下」と「最大」の両方を確認。縦・横で応援画面の先頭から末尾、全項目、購入済み表示、閉じるボタンまでスクロールして操作できることを確認。新しい有料購入は不要。
8. **TalkBack**：修正版で、ページへフォーカスを移してからダブルタップし、プレビューへ進めることを確認。TalkBackのカスタム操作「ページの選択／解除」で選択状態が切り替わることと、「ページをプレビュー」も使えることを確認。通常タッチ時の単タップ選択・ダブルタッププレビューも確認。応援画面の各項目・購入済み表示・閉じるへ順に移動できることも確認。連続3タップをプレビュー専用ジェスチャーとして数えるのではなく、フォーカスと実行を分ける。[Googleの標準操作説明](https://support.google.com/accessibility/android/answer/6151827?hl=ja)も参照。確認後は必要に応じTalkBackを元へ戻す。
9. **継続操作と復帰**：PDFの切替・画面回転・編集の取消／やり直し（特に左右回転後の角度と表示画像の復元）、読込・生成のキャンセルを行い、表示とページ数が整合すること、クラッシュせず復帰できることを確認。

結果は `1 合格、2 合格…` の形で記録。不合格は操作手順、期待した状態、実際の状態、端末・OS・文字サイズを添える。スクリーンショットは個人情報やPDF内容を含まない試験素材で保存する。
