Support

How to Get Help

If you encounter any issues or have feature requests, please use the GitHub Issues page for this project.

GitHub Issues are public. Send only information needed to explain the problem. Remove names, account identifiers, PDF contents and unnecessary screenshots or log details. Opening the issue page or copying diagnostics does not submit a report.

Common Questions

Is it free?

Yes, the core features of the app are free to use. You can support the developer via optional tipping in the app settings.

Are my PDFs safe?

PDF processing takes place on your device. PDF contents are not uploaded automatically. Sending diagnostics or logs is a separate action you choose. Check the content and destination before sharing.
