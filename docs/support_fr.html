Aide et support

Utilisez la page GitHub Issues pour les rapports de bugs ou suggestions.

Les tickets GitHub sont publics. N'envoyez que les informations nécessaires pour expliquer le problème. Supprimez les noms, les identifiants de compte, le contenu des PDF ainsi que les captures d'écran ou détails de journaux superflus. Ouvrir la page du ticket ou copier les diagnostics n'envoie aucun rapport.

Questions fréquentes

Est-ce gratuit ?

Oui, les fonctionnalités principales sont gratuites.

Mes PDF sont-ils en sécurité ?

Le traitement des PDF s'effectue sur votre appareil. Le contenu des PDF n'est pas téléversé automatiquement. L'envoi de diagnostics ou de journaux est une action distincte que vous choisissez. Vérifiez le contenu et la destination avant de partager.
