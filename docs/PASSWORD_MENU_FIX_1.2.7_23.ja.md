# 1.2.7（23）：パスワード入力と縦長メニューの修正

2026-11-03。対象はユーティリティ。項目1は合格から不合格へ訂正、項目4・6は合格、項目5は不合格のユーザー報告を受領。以前の項目2合格・3不合格も維持し、項目7〜9は結果待ち。

## 原因と修正

### パスワード付きPDF

- PdfProcessor.loadが認証エラーを含むすべての例外を握りつぶし、0ページを返していた。InvalidPasswordExceptionがViewModelへ到達せず、パスワード入力が表示されなかった。
- 読込エラーを呼出側へ伝え、未入力・誤入力では入力ダイアログを表示。ページ0・描画ページ数不整合は読込失敗として扱い、成功した空文書にしない。
- 正しいパスワードの入力後も従来のPdfRendererは暗号化PDFを直接開けないため、認証済みの描画用コピーをアプリの非公開キャッシュに作成する。パスワードは保持せず、元PDFを変更しない。一時コピーは作成失敗・描画用プロバイダー終了・次の文書読込時に削除する。
- 追加操作のパスワード再入力は、進行状況のisAppendingと切り離して保持。追加のつもりで文書全体を開き直すことを防ぐ。空の文書への追加は通常の読込にする。
- 入力欄を伏字・パスワード用キーボードに設定。新しいパスワードやPDFを外部へ送信しない。

### 縦長画面の3点メニュー

- 旧ドロップダウンには応援の項目自体は存在したが、長い一覧の末尾にあり、実機では到達できないとの報告を受領。また、横長メニューと比較して移動・回転・綴じ方向の操作が不足していた。
- 3点メニューから、全体をスクロールできるカテゴリ別ボトムシートを開く構造へ統一。初期表示を部分展開にせず、応援・ヘルプ・診断まで到達できるようにする。
- 移動・回転・右綴じ・表紙付き右綴じ・綴じ方向切替を含め、横長側と同じ31操作を用意。選択ページなどが必要な操作は、項目を隠さず条件に応じて無効にする。横長側のメニューは維持。
