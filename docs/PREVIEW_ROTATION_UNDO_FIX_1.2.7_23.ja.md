# 1.2.7（23）：プレビュー操作と回転取消の修正

2026-11-03。項目7合格・8不合格・9不合格の報告を受領。公開版の全初回結果は、2・4・6・7合格、1・3・5・8・9不合格。以下は未配信のローカル修正。

## 項目8：ページプレビュー

公開版ではアクセシビリティの標準OnClickが選択／解除であり、プレビューはカスタム操作だけだった。TalkBackでページへフォーカスを移してダブルタップしても、プレビューへ進まない割り当てだった。

- アクセシビリティの標準実行を「ページをプレビュー」へ変更。
- カスタム操作は「ページをプレビュー」と「ページの選択／解除」を用意し、選択状態の読み上げも維持。新しい選択／解除ラベルを全16リソース構成で翻訳。
- 通常タッチの単タップ選択・ダブルタッププレビューは維持。
- 再確認では、ページへのフォーカスと、その後のダブルタップによる実行を区別する。連続3タップ専用のジェスチャーを実装したものではない。[GoogleのTalkBack操作説明](https://support.google.com/accessibility/android/answer/6151827?hl=ja)を参照。

## 項目9：左右回転後の取消

履歴には回転角度を保存していたが、復元時に表示用ビットマップを戻していなかった。内部角度が戻っても、画面の画像が回転後のままで、取消が効いていない状態になっていた。

- 既存ページは、現在の角度と復元先の角度の差に応じて表示画像も復元。
- 削除等で現在の一覧にないページは、再取得した画像へ履歴の回転を適用して復元。
- 左回転角度を0〜359度へ正規化。
- 高解像度プレビューもページの回転角度へ追従。
