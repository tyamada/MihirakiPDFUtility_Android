隱私權政策

1. 裝置端處理與您選擇傳送的資訊

見開PDF實用工具 會在您的裝置上處理 PDF。應用程式不會自動將 PDF 內容、診斷資訊或記錄上傳給開發者。您使用的各項功能可能會在本地儲存原始 PDF、工作複本、設定與記錄。

您可以選擇複製診斷資訊、與其他應用程式分享記錄，或提交支援回報。您傳送的資訊會由您選擇的目的地接收；若是針對本專案的回報，則由開發者接收。傳送前請先確認內容與接收對象。

2. 關於應用程式內購

本應用程式包含用於支援開發的可選內購（打賞），由Google Play結算系統安全處理。

3. 關於權限

應用程式使用您選擇的檔案來開啟、編輯、儲存與匯出 PDF。應用程式可能會在本地保留最後成功開啟的原始 PDF 複本，以便在重新啟動後再次開啟。未儲存的編輯內容與 Undo 記錄不會自動儲存。範例下載會連線至 GitHub，該平臺會依據其自身政策處理連線資料。

4. 政策變更

本隱私權政策可能會不時更新。

5. 本地記錄與支援複本

本地記錄採用 24 小時清除閾值。清除作業會在相關記錄功能運作時執行，依據項目時間戳記或檔案修改時間進行判斷。這並不保證每筆項目剛好在建立 24 小時後刪除，尤其是在應用程式未執行的期間。

本地清除不會刪除已提交的回報、匯出的複本，或是由其他應用程式、服務提供者或備份所持有的複本。這些項目的保留與刪除是分開處理的。

由開發者管理的支援複本，其刪除目標是結案後 90 天。不再需要的複本會提前移除。未結案件與少數例外情況每週都會進行審核。此目標不會自動刪除公開的 GitHub Issues 或每一份外部複本與備份。

6. 支援回報與公開貼文

請僅傳送說明問題所需的資訊。開發者收到的支援資訊僅用於回覆請求與調查問題。姓名、帳號名稱、訊息內文與附件通常不會被複製到獨立的追蹤表中。若需要進行追蹤，僅會保留案件編號、issue 連結、日期、狀態與刪除紀錄。

GitHub Issues 是公開的。個人資料、貼文與附件皆依照 GitHub 的政策處理。編輯或刪除您自己的留言，與刪除整個 issue 不同；刪除整個 issue 需要存放庫擁有者或獲得授權的管理員權限。

若要請求移除本專案回報中的資訊，請透過原有的支援管道聯絡開發者。請勿在公開請求中再次發布敏感資訊。公開貼文、服務紀錄、快取與備份各有獨立的控制機制；應用程式無法保證清除所有複本。
