## 3. 事前準備チェックリスト

1. **初回6地域の公開確認（Stage 0 完了条件）**
   - 製品版 `1.2.16 (32)` の審査承認・公開完了後、クラッシュ0件・ANR0件・ポリシー問題0件を確認。
   - `README.md` / `README_ja.md` / `docs/index*.html` の「一般公開前」記載を Google Play リンク＋公開状況へ更新。
2. **Stage 1（14地域）実施前チェック**
   - EU DSA 取引業者ステータス（`プライベート / 非事業者` 申告済み・ポリシータスク0件）を Play Console で確認（独・仏・伊追加に必須）。
   - `de-DE` / `fr-FR` / `it-IT` のストア掲載文（[store_listing/](../store_listing/) に準備済み）を登録し、可能であれば各言語のスクリーンショットを撮影・差し替え。
3. **Stage 2（Wave 1〜3・48地域）実施前チェック**
   - 上記16か国の1回限りの商品価格を Play Console で Android Viewer 準拠へ同期・再読込確認し、最新価格スナップショット JSON を更新。
   - `es-ES` / `pt-BR` / `id` / `fil` / `ne-NP` / `vi` のストア掲載文（作成済み・文字数検証済み）を Play Console へ登録し、必要に応じてローカライズスクリーンショットを撮影・差し替え。
   - `scripts/capture_store_screenshots.py` は現在旧 Viewer 向け設定のままのため、自動撮影を再開する場合は Utility パッケージ（`com.takumayamada22.pdfutility`）向けへ構成を見直してから実行する。
4. **公開後追跡**
