# こよみバッジの確定方針（2026-11-19）

この文書を最新方針とし、2026-11-03の将来仕様案にある「終了未定」「トースト」の記述より優先する。旧未コミットの仕様案原本は保持する。

## 無料自動付与と保存

既存利用者・新規利用者の双方が対象。対応版での付与判定時の端末現在時刻を使う。ストア初回入手日・同一ストアアカウント・購入履歴は判定や無料復元に使わず、購入済み取引も作らない。

- 開始（含む）: 2026-11-01 00:00 JST = 2026-10-31T15:00:00Z。
- 終了日（含む）: 2027-12-31 JST。
- 排他的締切: 2028-01-01 00:00 JST = 2027-12-31T15:00:00Z、Unix秒1830265200。
- 比較は`Instant`。端末の表示タイムゾーンが変わっても締切は同じ絶対時刻。
- 既存の`commemorative_badge_prefs` / `acquired_badge_ids` / `koyomi_commemorative`を維持する。未知の保存済みIDも消さない。
- 同期保存の成功後にだけ新規取得として扱い、保存失敗では付与・通知しない。UIからはIO上で保存する。
- 保存済みIDは締切後も失効させない。未保存のまま締切後に初めて対応版を起動しても新規付与しない。状態消失時にストアアカウントだけで無料復元する方式は導入しない。

## 通知と詳細

取得通知は従来のダイアログ方式を維持し、TalkBack利用の有無にかかわらず手動で閉じる。タイマーや明示的フォーカス要求は追加しない。読書文書が開いている間・処理中・他のシートやダイアログ表示中は開始画面まで待機させる。待機要求はプロセス内のViewModelに保持し、再起動時には再生しない。取得済みIDの永続保存とは分離する。

閉じる操作で消すのは通知要求だけで、取得済みバッジは消さない。アプリ情報の取得済みバッジを押すと、拡大画像・名称・説明と閉じる操作を持つ詳細を表示する。名称と説明は行数制限・省略なし、本文は高さ制限内でスクロール、閉じるボタンは固定する。詳細対象のIDは画面再生成に備えて保存可能なUI状態とする。

応援画面には有料チップの既存導線だけがあり、こよみの既存無料導線はなかったため、購入と混同する新しい導線は追加しない。旧テスト限定購入フラグ・旧こよみ商品は再導入しない。

## 配信・検証計画

本変更はローカル実装のみ。サンプル最新版JSON対応、既存Alpha/AAB、製品版アクセス申請の待機・優先方針は保持し、インストール・購入・push・ストア設定変更・アップロード・提出・公開は行わない。

ローカル試験の結果と未実施項目は `validation/koyomi-policy-20261119/VERIFICATION.json` を参照。実機/エミュレータの禁止を維持し、実際のTalkBackフォーカス移動・実発話・実機回転は未判定とする。将来それらが許可された場合に、日英だけで追加確認する。現行配信用1.2.14（30）AABにはこの変更は含まれず、将来の配信には別の版上げ・配信準備が必要。
