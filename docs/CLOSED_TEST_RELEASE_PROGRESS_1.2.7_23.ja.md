- 公開HTML44ページの欠落参照48件・言語選択ラベル44件を修正。READMEの言語リンク、画像、現行メニューの説明を修正。9言語のリリースノートを作成。

## Lint警告の判断

- OldTargetApi 1件：targetSdk36。OSターゲット更新は互換性回帰を伴うため、通知だけを理由に今回引き上げない。
- AndroidGradlePluginVersion 1件：Gradle8.14.5からの更新通知。現在の構成で検証する。
- GradleDependency 7件：core、documentfile、lifecycle2件、activity、Material、Billingの更新通知。メジャー更新等を今回へ混ぜない。
- TrustAllX509TrustManager 3件：PDFBox経由のBouncy Castle EST補助クラス。アプリのHTTPS処理に独自のtrust-allは見つからず、Release R8のusage.txtでは該当ESTクラスの削除を確認した。依存全体の無欠陥を保証する判断ではない。警告は表示したまま維持する。

旧v7報告の単体1件不合格と警告8件は過去の結果であり、今回の候補に流用しない。今回の実行ログ・JUnit XML・Lint XMLで上表を更新する。
