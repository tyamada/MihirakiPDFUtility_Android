मद्दत र समर्थन

कृपया बग रिपोर्ट वा सुविधा अनुरोधहरूको लागि GitHub Issues पृष्ठ प्रयोग गर्नुहोस्।

GitHub Issues सार्वजनिक हुन्छन्। समस्या व्याख्या गर्न आवश्यक जानकारी मात्र पठाउनुहोस्। नाम, खाता पहिचानकर्ता, PDF सामग्री र अनावश्यक स्क्रिनसट वा लग विवरणहरू हटाउनुहोस्। समस्या पृष्ठ खोल्दा वा विश्लेषण कपी गर्दा रिपोर्ट पेस हुँदैन।

सहायता रिपोर्टहरू कसरी ह्यान्डल गरिन्छ · लग सफाइ र सहायता जानकारी

GitHub मा Issue खोल्नुहोस्

बारम्बार सोधिने प्रश्नहरू

के यो नि:शुल्क छ?

हो, कोर सुविधाहरू निःशुल्क छन्।

के मेरो PDF सुरक्षित छ?

PDF प्रोसेसिङ तपाईंको डिभाइसमै हुन्छ। PDF सामग्रीहरू स्वतः अपलोड हुँदैनन्। विश्लेषण वा लगहरू पठाउनु तपाईंले रोज्ने छुट्टै कार्य हो। सेयर गर्नुअघि सामग्री र गन्तव्य जाँच गर्नुहोस्।
