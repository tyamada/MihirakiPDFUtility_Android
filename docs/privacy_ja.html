プライバシーポリシー

1. 端末内処理と利用者が送る情報

見開きPDFユーティリティはPDFを端末内で処理します。アプリがPDF本文・診断結果・ログを開発者へ自動送信することはありません。利用する機能のため、元PDF・作業用コピー・設定・ログを端末内に保存する場合があります。

利用者は診断結果のコピー、他アプリでのログ共有、サポートへの報告を選べます。送った情報は選択した送信先に届き、このプロジェクトへの報告では開発者が受け取る場合があります。送信前に内容と送信先を確認してください。

2. アプリ内購入について

本アプリには、開発を支援するためのオプションのアプリ内購入（チップ）が含まれています。これらの取引はGoogle Playの決済システムによって安全に処理されます。開発者がお客様の支払い詳細（クレジットカード番号など）にアクセスすることはありません。

3. 権限について

利用者が選んだファイルをPDFの読み込み・編集・保存・書き出しに使います。再起動後に開き直すため、最後に正常に開いた元PDFのコピーを端末内に保持する場合があります。未保存の編集やUndo履歴は自動保存しません。サンプル取得時はGitHubへ接続し、接続情報は同サービスの方針に従って扱われます。

4. ポリシーの変更について

本プライバシーポリシーは随時更新されることがあります。変更がないか定期的にこのページを確認することをお勧めします。

5. 端末内ログとサポート用コピー

端末内ログは24時間を基準に整理します。該当するログ機能が動作する際に、記録時刻またはファイルの最終更新時刻を使って整理します。アプリが動作していない間も含め、すべての記録を作成からちょうど24時間で削除することを保証するものではありません。

端末内の整理では、送信済みの報告、書き出したコピー、他アプリ・サービス・バックアップにあるコピーは削除されません。それぞれの保持・削除は別に扱われます。

開発者が管理するサポート用コピーは、案件の最終対応完了日から90日を削除の目標とし、不要になったものはそれより早く削除します。未解決案件と限定的な例外は週次で見直します。この目標で公開GitHub Issueやすべての外部コピー・バックアップが自動削除されるわけではありません。

6. サポート報告と公開投稿

問題の説明に必要な情報だけを送ってください。開発者が受け取るサポート情報は、問い合わせへの回答と問題の調査に使います。氏名・アカウントのハンドル・メッセージ本文・添付を別の管理表へ通常は転記しません。管理が必要な場合も、案件ID・Issueリンク・日付・状態・削除記録に限定します。

GitHub Issuesへの投稿は公開されます。プロフィール・投稿・添付はGitHubの方針に従って扱われます。自分のコメントの編集・削除とIssue全体の削除は別で、Issue全体の削除にはリポジトリ所有者または権限を持つ管理者による操作が必要です。

このプロジェクトへの報告に含めた情報の削除を相談する場合は、報告時のサポート経路で開発者へ連絡してください。削除依頼のために機密情報を公開投稿し直さないでください。公開投稿・サービス側記録・キャッシュ・バックアップは管理方法が異なり、アプリが全コピーの消去を保証することはできません。
