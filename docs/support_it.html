Supporto

Come ricevere aiuto

Se riscontri problemi o hai richieste di nuove funzionalità, utilizza la pagina GitHub Issues per questo progetto.

Le issue di GitHub sono pubbliche. Invia solo le informazioni necessarie a chiarire il problema. Rimuovi nomi, identificatori di account, contenuti di file PDF e screenshot o dettagli dei log non necessari. L'apertura della pagina delle issue o la copia della diagnostica non invia alcuna segnalazione.

Domande frequenti

È gratuito?

Sì, le funzionalità principali dell'app sono gratuite. Puoi sostenere lo sviluppatore tramite mance opzionali nelle impostazioni dell'app.

I miei PDF sono al sicuro?

L'elaborazione dei PDF avviene sul tuo dispositivo. I contenuti dei PDF non vengono caricati automaticamente. L'invio di dati di diagnostica o log è un'azione separata che scegli tu. Verifica contenuto e destinatario prima della condivisione.
