# 1.2.7（23）：実機項目3の言語フィルター修正

2026-11-03。対象はユーティリティ。項目1・2はユーザー報告で合格、項目3は不合格、項目4〜9は結果待ち。修正版の実機確認結果は未受領。

## 原因

- 言語ラベルの分岐が7言語しかなく、スペイン語・イタリア語などはコードの大文字へフォールバックしていた。選択欄とメニューに同じ分岐が重複していた。
- 言語一覧はカタログの登録順で表示され、ソートされていなかった。
- カタログは33件で、testdataの「ためし部」漫画42件のうち9言語の第3話が未登録だった。「すべて」は登録済み33件だけを表示していた。

## 修正

- 全14言語の原語・英語名を共通定義し、選択欄とメニューで同じラベルを使用。例：Español (Spanish)、Italiano (Italian)、简体中文 (Chinese (Simplified))。English・Filipinoは原語と英語名が同一のため重複表記しない。
- 「すべて」を先頭に固定し、言語は英語名のアルファベット順に表示。漫画の話数順とは独立した並び順とする。
- ドイツ語・フランス語・スペイン語・イタリア語・ポルトガル語・ベトナム語・インドネシア語・フィリピン語・ネパール語の第3話9件を追加し、14言語×3話＝42件にする。フィリピン語のコードfilと第3話ファイルのtlを対応付け、既存のファイル名・ダウンロード済みデータを保持。
- 追加9件の配布ファイルとtestdataのSHA-256一致を確認し、追跡用SHA256SUMSを42件へ更新。対象はtameshibu*.pdfの漫画のみ。負荷試験用PDFやその他の試験素材を追加しない。

## ローカル検証

|カタログ|全42件のファイル存在と独立したハッシュ一覧に一致|

|専用エミュレーターの画面回帰試験|1件成功。スペイン語／イタリア語を実際に選択して各3話を確認。「すべて」選択で42件・14言語各3話を確認|
|ユーザー実機での項目3再確認|未実施／結果未受領|
